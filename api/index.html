    An inferer for making statistical inference

    Parameters:

    Name Type Description Default
    learner estimator or crosser object

    The (fitted) learner being inferred.

    		 required
    sampler estimator or crosser object

    A sampler that predicts \(x_j\) by \(x_{-j}\). When sampler is a crosser, its cross-validator (splitter) must be identical to the learner. If sampler doesn't have a sample method, the residual permutation approach will be used for resampling.

    		 None
    competitor estimator or crosser object

    A competitor that predicts \(y\) by \(x_{-j}\). If competitor is a crosser, its cross-validator (splitter) must be identical to the learner.

    		 None
    removal int, str, or list

    A label for removing \(x_j\). - When learner is trained with numpy array, removal must be column index(es) of \(x_j\). - When learner is trained with DataFrame, removal must be column name(s) of \(x_j\).

    		 None
    method ('HRT', 'RPT', 'CPI', 'LOCO', 'PIE')

    The method for making inference. It provides a control for implementing a specific procedure.

    		 "HRT"
    loss_func {"mean_squared_error", "mean_absolute_error", 
        "zero_one_loss", "log_loss"}, default=None

    The loss function for measuring the difference between \(y\) and its prediction.

    - When `learner` is a regressor, `None` means
  "mean_squared_error".
- When `learner` is a classifier, `None` means
  "log_loss".
    		None
    null_dist ('resampling', 'normality', 'permutation')

    The way for constructing a null distribution of test statistic.

    - When `method` is "HRT", "RPT", `None` means "resampling".
- When `method` is "CPI", "LOCO" or "PIE", `None` means
  "normality".
    		"resampling"
    double_split bool

    An indicator for double splitting. If applicable,

    - When `method` is "LOCO", `None` means `False`
- When `method` is "PIE", `None` means `True`.

    With double splitting, each test set is randomly divided into two halves; the learner's loss is evaluated on one half and the competitor's loss on the other.

    		 None
    perturb_size non-negative float

    The standard deviation of random error for pertubation. If applicable, None means 0.

    		 None
    n_copies int

    The number of copies for resampling \(x_j\) given \(x_{-j}\). If applicable,

    - When `method` is "HRT", "RPT", `None` means 2000.
- When `method` is "CPI", `None` means 1.
    		None
    n_permutations int

    The number of permutations. If applicable, None means 2000.

    		 None
    random_state int or None

    Controls the randomness of sampling, permutation, perturbation and double splitting. Independent random streams are derived from it for every split (fold) and every source of randomness. Unlike random_state in scikit-learn, RandomState is not allowed here.

    		 None

    Attributes:

    Name Type Description
    method_, loss_func_, null_dist_, double_split_, n_copies_, n_permutations_

    The settings actually used, i.e., the corresponding arguments with None replaced by their defaults. The arguments themselves are kept unchanged.
    l_losses_ list of ndarray

    Per-observation losses of learner, one array per split.
    r_losses_ list of ndarray

    Per-observation losses after removing \(x_j\) (resampled \(x_j\) for CITs, competitor for RITs), one array per split.
    null_values_ list of ndarray or None

    Null distribution of the test statistic for each split (None when null_dist is "normality").

    summarize(cross_fit=None, combine=None, reverse=False, verbose=True)

    Summarize inference results

    Parameters:

    Name Type Description Default
    cross_fit bool

    If True, inference results will be integrated across folds by cross-fitting strategy. It is applicable only if learner is a Crosser with n_folds > 1. If applicable, None means True; Otherwise, None means False.

    		 None
    combine bool

    If True, inference results will be combined across folds and repeats. For estimates and std_error, simple average is used for combination. For p_value, the following p-value combination methods are reported (with \(m\) p-values and order statistics \(p_{(1)} \le ... \le p_{(m)}\)):

    - "gmean": $e$ times the geometric mean.
- "median": twice the median.
- "min": $m p_{(1)}$ (Bonferroni).
- "hmean": $e \log(m)$ times the harmonic mean.
- "hommel": Hommel's combination.
- "cauchy": Cauchy combination test.

    It is applicable only if learner is a Crosser with n_splits > 1. If n_repeats > 1, None means True; Otherwise, None means False.

    		 None
    reverse bool

    If True, negative values of estimate will be reported.

    		 False
    verbose bool

    Controls the verbosity.

    		 True

    Returns:

    Name Type Description
    summary DataFrame

    A summary for inference results.

    Cross-fitting

    Bases: BaseEstimator

    An object for repeated cross-fitting

    Parameters:

    Name Type Description Default
    estimator estimator object

    The base estimator for repeated cross-fitting.

    		 required
    cv cross-validation generator

    The cross-validation generator for repeated cross-fitting. It must be a class member of KFold, RepeatedKFold, or ShuffleSplit. Its random_state must be an int (or None for KFold without shuffling) so that every call to split yields the same folds.

    		 required
    scoring str or callable

    Strategy to evaluate the performance of the cross-validated model when using summarize. To see availble scoring methods via str, use sklearn.get_scorer_names().

    - For regression tasks, `None` means "r2".
- For classification tasks, `None` means "accuracy".
    		None

    Attributes:

    Name Type Description
    estimators_ list of estimators

    The fitted estimators, one per split.
    classes_ list

    Class labels (classifiers only).
    label_binarizer_ LabelBinarizer

    Binarizer fitted on all class labels (classifiers only).
    val_scores_, train_scores_, test_scores_ ndarray of shape (n_splits,)

    Validation (best_score_ of the estimator, if any), training and test scores of each split.

    summarize(cross_fit=None, combine=None, reverse=False, verbose=True)

    Summarize repeated cross-fitting results

    Parameters:

    Name Type Description Default
    cross_fit bool

    If True, score values will be averaged across folds. It is applicable if n_folds > 1. If applicable, None means True; Otherwise, None means False.

    		 None
    combine bool

    If True, score values will be averaged across folds and repeats. It is applicable if n_splits > 1. If n_repeats > 1, None means True; Otherwise, None means False.

    		 None
    reverse bool

    If True, negative score values will be reported. Note that by default a larger score value means better in scikit-learn.

    		 False
    verbose bool

    Controls the verbosity.

    		 True

    Returns:

    Name Type Description
    summary DataFrame

    A summary for validation, train, and test scores (val_score, train_score, and test_score). The validation scores are only presented if estimator.best_score_ is available.

    predict(X, *, split=None)

    Predict with one split's estimator, or aggregate all splits.

    With split=None, regression predictions are averaged and classification predictions are combined by majority vote (ties go to the smallest label).

    predict_proba(X, *, split=None)

    Class probabilities of one split, or their average.

    predict_log_proba(X, *, split=None)

    Log-probabilities of one split, or their average.

    decision_function(X, *, split=None)

    Decision function of one split, or its average.

    Warnings and errors

    Bases: UserWarning

    Warning raised when the inference setup may leak test information.

    It is emitted when learner is a Crosser but sampler (CIT) or competitor (RIT) is an ordinary estimator. If that estimator was fitted on data that includes the test folds of learner, the resulting test is invalid. Use warnings.simplefilter("error", LeakageWarning) to turn it into an error.

    Bases: ValueError

    Exception raised if an inferer is summarized before infer.

    Bases: ValueError, TypeError

    Exception raised for an invalid argument.

    It subclasses both ValueError and TypeError (as scikit-learn's InvalidParameterError does), so code written against tofi 0.0.1, which raised ValueError for every invalid argument, keeps working.
